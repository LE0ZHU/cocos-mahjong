# 麻将（Cocos Creator 3D 版）

单人对局 · 三家 AI 的中国麻将。原生 + Web 双端，界面按桌面第一视角做了透视与自适应。

引擎：**Cocos Creator 3.8.8** ｜ 语言：TypeScript（`strict: false`，target ES2015）

---

## 运行

1. 用 Cocos Creator 3.8.8 打开本目录
2. 打开场景 `assets/game.scene`，点预览（浏览器）或构建到 Android/iOS
3. 场景里只有一个 `Main` 脚本挂在 Canvas 下，`GameManager` 由它在运行时创建

## 操作

| 操作 | 效果 |
|---|---|
| 点击手牌 | 选中（突出显示） |
| 再次点击同一张 | 打出 |
| 按住手牌往上拖，出手牌区后松手 | 打出（牌跟着手指走） |
| 点击其他区域 | 取消选中 |
| 左上角「重新开始」 | 按当前规则重开一局（累计分与连庄保留） |
| 「返回主页面」 | 结束会话，累计分与连庄清零 |
| 听牌时手牌左侧出现「听牌」按钮 | 宣告听牌（加 1 番） |

出牌没有按钮：轮到自己自动摸牌，点两下手牌就出。

## 玩法

**流程**：发牌 → 摸/出 → 副露（吃/碰/杠/续杠）→ 胡牌或流局

**胡牌方式**：自摸必可；开启「吃胡」后也可胡别人打出的牌；补杠时可被抢杠。

**一炮多响**：同一张牌可以被多家同时胡。玩家逐个决定是否参与，AI 自动参与。

**听牌（立直）**：手牌听牌后可点「听牌」亮明给对手看，加 1 番。宣告后本局不能再吃/碰/杠，且出牌必须保持听牌。AI 听牌后自动亮明，并改为只打保持听牌的牌。

### 番型与计分

底分 1 分，**每 1 番翻一倍**，8 番封顶（= 256 分）。

| 类别 | 番型 |
|---|---|
| 牌型 | 十三幺 6 ｜ 七对 2 ｜ 对对胡 2 ｜ 平胡 0 |
| 花色 | 清一色 4 ｜ 混一色 2 ｜ 字一色 2 |
| 状态 | 自摸 1 ｜ 门清 1 ｜ 立直 1 ｜ 杠上开花 1 ｜ 抢杠胡 1 ｜ 海底捞月 1 |
| 连庄 | 连续第 N 次胡加 (N−1) 番，最多 3 番 |

**支付**：自摸 = 三家各付一份；点炮 / 抢杠 = 付分方一次付清；一炮多响时付分方需赔付给每家赢家。
**连庄与累计分跨局保留**，只有返回主页面才清零（单局内不可能有"第二次连庄"）。

### 设置项（主页面 → 设置规则，下一局生效）

| 选项 | 说明 |
|---|---|
| 吃牌 | 只能吃上家打出的牌 |
| 续杠 | 碰过之后再摸到同一张，可补成杠 |
| 吃胡 | 听牌时别人打出所听的牌，可选择胡 |
| 抢杠胡 | 别人补杠时可以抢那张牌胡（优先于补杠） |
| 一炮多响 | 多家同时听同一张牌时可一起胡 |
| 听牌宣言 | 亮明听牌加 1 番，之后不可吃碰杠 |
| AI 思考速度 | 快 / 常规 / 慢（出牌间隔 0.22 / 0.5 / 0.9 秒） |

## 目录结构

```
assets/
  game.scene              唯一场景（Canvas + Camera + Main）
  resources/              运行时 resources.load 的资源
    menu_bg.png           主菜单背景
    tiles/                34 种牌面图
    audio/                bgm + 出牌/点击/弃牌音效
  scripts/
    Main.ts               主场景脚本：牌桌 UI、交互、动画、布局（1896 行）
    core/                 纯逻辑，不依赖 cc 引擎 —— 可脱离引擎单测
      TileDefine.ts       花色/点数/配色常量
      Tile.ts             单张牌
      Wall.ts             136 张牌墙 + 洗牌 + 摸牌
      Meld.ts / MeldDetector.ts   副露数据与吃碰杠检测
      HuChecker.ts        胡牌判定 + 牌型拆解（analyze）+ 听牌枚举
      HuScore.ts          番型判定与计分 + 结算数据结构
    game/                 规则与 AI
      Player.ts           一家的手牌/副露/弃牌/听牌状态（纯逻辑）
      AIBrain.ts          AI 出牌与副露决策（纯逻辑）
      GameRules.ts        规则开关（依赖 cc 的 sys 做 localStorage 持久化）
    managers/
      GameManager.ts      全局状态机：回合调度、胡牌判定、计分结算（1168 行）
    ui/
      UIFactory.ts        控件工厂（牌节点/按钮/文字/3D 底框）
      TileView.ts         牌的交互组件（点击选中、拖拽出牌）
      TileImage.ts        牌面图预加载
      Anim.ts             补间动画封装
      MenuUI.ts           主页面 / 规则设置页
      SettlementPanel.ts  结算面板（番型 + 四家得失分 + 四家手牌）
    audio/Sound.ts        音效与 BGM
tools/                    构建/排查用 PowerShell 与 Python 脚本
settings/                 Cocos 项目设置
```

**架构约定**：`core/` 全部与 `game/` 的 `Player`/`AIBrain` 不 import `cc`，
因此可以用 tsc 编译后用 node 直接跑单测（见 `AGENTS.md`）。唯一例外是
`GameRules.ts`，它要用引擎的 `sys` 读写 localStorage。

## 技术要点

- **自适应**：内容按宽度铺满（`_gameRoot.scale = 设计宽 / 1680`），纵向贴可见区边界，形成贴近桌面的第一视角；转屏自动重排
- **原生兼容**：原生（JSB）平台在 `onLoad` 阶段画的 `Graphics` 不上屏，所有静态图形延后一帧绘制，页面重新显示时用 `repaintButtons()` 补画按钮底框
- **牌面**：优先用真实牌面图，加载失败时退化为矢量绘制
